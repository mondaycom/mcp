# Example 1 — Default mode, one pipeline board, posted to monday on request

Shows: one Deals board, the three activity reads (board activity, updates, timeline), the timeline correcting a "going cold" call, the brief in chat, and a single confirmation before posting it on the user's "My Morning" item. Without "post it to monday" the run would end after the chat brief.

---

**User:**
> morning briefing, and post it to monday

**Step 0–1** — *[`get_user_context` → `{ id: 487214, name: "Kevin Cheng" }`]* Mode Default; destination `monday` (asked); verbosity `full`.

**Step 2–4** — favorites contain one pipeline board, `Deals` (10046221612). *[`get_board_info({ boardId: 10046221612, filters: { columns: { only: true } } })` → stage `status` (Discovery 0, Proposal 1, Negotiation 2, Won 3 `is_done`, Lost 4), owner `person`, value `numbers` ($), probability `numbers` (%), close `date_close`, last touch `date_touch`]*

**Step 5 — pull** (Tue 2026-05-05, window = last 24h)
*[5a `get_board_items_page({ boardId: 10046221612, includeColumns: true, filters: [{ columnId: "status", operator: "not_any_of", compareValue: [3, 4] }], limit: 500 })` → 38 active deals]*
*[5b `get_board_activity({ boardId: 10046221612, fromDate: "2026-05-04T07:00:00Z", toDate: "2026-05-05T07:00:00Z" })` → Northwind moved to Won]*
*[5c `get_updates({ objectType: "Board", objectIds: ["10046221612"], includeItemUpdates: true, fromDate: "2026-05-04T07:00:00Z", toDate: "2026-05-05T07:00:00Z", limit: 100 })` → 4 updates, 1 meeting-to-deal recap on Helix Bio]*
*[first synthesis pass → 9 deals in Needs you today or close to it]*
*[5d `get-timeline-items({ item_id: <id>, limit: 10 })` for 9 deals, going-cold candidates first; `get-custom-activities` once to map `custom` entries → Gradient AI has a call logged yesterday, so it leaves Going cold]*

## What this example demonstrates

- Posting to monday happens only because the user asked; one confirmation, and the `daily-briefing · <date>` footer lets a re-run reply instead of duplicating.
- Yesterday's movements come from stage changes in `get_board_activity`, not "updated in the last 24h".
- The timeline check moved a deal out of Going cold; the meeting-to-deal recap in the updates feed counted as a touch for Helix Bio.
- Every section is a template section; header counts equal printed lines; the activity line says how many items were checked.
