# Example 2 — Two pipeline boards, non-English labels, permission fallback, Proactive

Shows: two boards of the same type (ask once), French stage labels resolved by `is_done`, a "My Morning" item the user can't post on (falls back to a private doc), Proactive nudges limited to the user's own deals and de-duplicated.

## What this example demonstrates

- Same-type boards → one question with "all of them"; the choice is kept for the session.
- Non-English labels resolved by `is_done` and the Lost rule, never by English text.
- Permission fallback: update → private doc → chat, without stopping.
- Proactive writes only on the user's own deals, and never a second nudge on the same deal within 7 days.
- Items beyond the 10 timeline checks are marked "(timeline not checked)".
