# meeting-to-deal — templates

Loaded by `SKILL.md` Steps 7 and 10. Keep the field order; the reference line is what makes re-runs idempotent.

## Per-deal recap (`create_update` body)

`create_update` renders HTML, not Markdown. Post exactly this shape, **as one line with no newlines between tags** (monday turns newlines into extra `<br>` blank lines; the shape is wrapped here only for reading). No HTML comments either — monday strips them, which is why the reference is a visible line:

```html
<h3>Meeting recap — <meeting title></h3>
<p><i><meeting date> · <duration>m · <attendee count> attendees · ref meeting-to-deal/<meeting-ref></i></p>
<p><b>Key points</b></p>
<ul><li>...</li></ul>
<p><b>Commitments</b></p>
<ul><li><person> → <commitment> (due <date or "open">)</li></ul>
<p><b>Open questions</b></p>
<ul><li>...</li></ul>
<p><b>Stage signal</b></p>
<p><"Applied: <old> → <new>" | "Suggested (not applied): <old> → <new> — <reason>" | "No stage change"></p>
<p><i>Generated by Claude · meeting-to-deal · <ISO timestamp></i></p>
```

- Omit Key points, Commitments or Open questions when empty; the first two lines, Stage signal and the footer are always kept.
- "Applied" only for an edit that succeeded before the recap was posted (SKILL Step 7c).
- `<meeting-ref>` is the Notetaker meeting id. For manual input (Step 3b) use `manual-<YYYYMMDD>-<title: lowercase, letters and digits only, words joined by dashes, max 40 characters>`.
- The reference line sits near the top on purpose: `get_updates` truncates bodies over 2,000 characters, and the idempotency scan must still see it.
- Multi-deal meetings (SKILL Step 5, item 4) add `<p><i>Meeting also discussed: <other deal></i></p>` right after the reference line.

Filled example:

```html
<h3>Meeting recap — Quarterly Review — Acme Corp</h3>
<p><i>Jun 14, 2026 · 45m · 4 attendees · ref meeting-to-deal/8812345</i></p>
<p><b>Key points</b></p>
<ul><li>Q3 expansion scope — 3 additional seats requested</li><li>Budget approved at Acme, pending procurement sign-off</li></ul>
<p><b>Commitments</b></p>
<ul><li>Sarah (Acme) → send updated SOW (due Jun 18)</li><li>Kevin → schedule legal review call (due Jun 20)</li></ul>
<p><b>Stage signal</b></p>
<p>Applied: Proposal → Negotiation ("we agreed to open the redline today")</p>
<p><i>Generated by Claude · meeting-to-deal · 2026-06-15T09:00:00Z</i></p>
```

## Sync summary doc (`create_doc` / `update_doc` markdown)

Title: `Meeting sync — <Mon DD, YYYY>`. Omit any section with zero entries.

```markdown
# Meeting sync — <Mon DD, YYYY>

## Matched (<N>)
- <meeting title> → <deal name> (<deal url>) <"· stage → <new>" if applied>

## Multi-deal (<N>)
- <meeting title> → <deal A> + <deal B>

## Ambiguous, not logged (<N>)
- <meeting title> — candidates: <deal A>, <deal B> — re-run and pick the deal

## Already logged (<N>)
- <meeting title> → <deal name> — recap from an earlier run kept

## Unmatched (<N>)
- <meeting title> — external attendees: <emails> — no matching deal

## Skipped (<N>)
- <meeting title> — <"internal-only" | "transcript pending" | "not accessible">

## Pending your review (<N>)
- <deal name> — <suggested stage change or last-touch> — not applied (<"Silent mode" | "you skipped stage edits">)

## Contacts created (<N>)
- <name> (<email>) → linked to <deal>

## Contacts pending manual link (<N>)
- <name> (<email>) — contact created, deal link failed — set it on the Contacts board

## Commitments due this week (<N>) — Proactive runs only
- <deal> — <person> → <commitment> (due <date>)

---
Generated by Claude · meeting-to-deal · <ISO timestamp>
```

When the same-day doc already exists, append instead of creating a new one: `update_doc` with one `add_markdown_content` operation whose markdown starts with `## Run at <HH:MM>` followed by the sections above (without the `#` title).

## Chat summary (last line of every run)

```
Synced <N> meetings to <M> deals (<S> skipped as internal). <K> unmatched, <A> ambiguous, <L> contacts created (<P> link pending). Doc: <url>.
```

## Error handling (SKILL.md)

| Failure | Behavior |
|---|---|
| Connector missing | Step 0 stops with the install message. |
| Notetaker unavailable or 0 meetings | Step 3b manual input. |
| No Deals board | Sync doc only; suggest workspace-builder. |
| Ambiguous match | Ask (Default/Proactive); list as "Ambiguous, not logged" (Silent). |
| Recap already logged | Skip; list under "Already logged". |
| Stage label not on the board | Drop the edit; list under "Pending your review". |
| Contact relation write fails | Create without the link; list under "Contacts pending manual link". |
| 429 on any call | Back off 3 times (1s, 2s, 4s); then stop and list what was written. |
| Transcript empty / still processing | Skip the meeting; list as "transcript pending". |
| Permission error on one deal or contact | Skip that one; continue. |
